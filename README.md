# Divine Group of Companies — Next.js

Converted from the original HTML website into a Next.js App Router project.

## Run in VS Code
1. Extract ZIP and open the `divine-nextjs` folder in VS Code.
2. Open Terminal > New Terminal.
3. Run `npm install`.
4. Run `npm run dev`.
5. Open http://localhost:3000.

## Production
Run `npm run build` and `npm start`, or deploy the project to Vercel.

## Edit content
- `lib/data.js`: company information, six services, blog articles and WhatsApp number.
- `app/globals.css`: design and responsiveness.
- `components/Site.jsx`: header, dropdown, footer, cards and contact form.
- `public/assets/divine-logo.jpg`: logo.

The enquiry form sends a prefilled WhatsApp message; it does not save messages to a database.
Blog copy is starter content and should be reviewed before publication. NIC codes do not establish sector-specific regulatory licences.
